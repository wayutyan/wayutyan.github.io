まずはじめに

作成するために特別、新しいソフトを用意する必要はありません。すべてwindowsに標準で付属しているソフトを使って作成可能です。

ページを作るためのソフト

HTMLを書くために、「テキストエディタ」というソフトが必要になります。「テキストエディタ」とはただ単に文字を編集するソフトのことです。現代で主に使われているソフトを示します。

ソフト名 説明
メモ帳 windows標準付属ソフト
サクラエディタ 国産のテキストエディタ
Visual Studio Code 高機能でプログラミング向けのテキストエディタ

ページを見るためのソフト

作ったページを見るためには、「ブラウザ」というソフトがひつようになります。これは、普段ネットを見るときに使っている、「Microsoft Edge」や「Google Chrome」のことです。
このほかにもブラウザにはいろいろな種類があり、HTMLやCSSの解釈が違う可能性もあるので、慣れてきたらほかのブラウザでも表示確認をしてみるといいと思います。
以下に代表的なブラウザを示します。

ソフト名 説明
Microsoft Edge windows標準付属ソフト
Google Chrome 世界的に使われているブラウザ
Brave 需要が高まっている広告ブロッカーを標準搭載したブラウザ
Opera セキュリティ重視のブラウザで、無料VPNも搭載している
